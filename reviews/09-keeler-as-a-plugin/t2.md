**Review found four defects; two fixed here, two left as proposed spec
amendments.**

1. **Fixed — three lines of detection were unpinned** (`tests/installer.rs`).
   `.claude/skills/property-testing`, the `.justfile` spelling and the
   rooting of the removal line could each be deleted from `install.sh` with
   the suite still green: `STALE_MARKERS` follows the scenarios' fixture,
   which names neither of the first two. `the_traces_the_scenarios_do_not_name_are_found_too`
   now covers both, and the scenario test asserts the destination is named
   beside the removal line. (The case-insensitive match was already pinned:
   the fixture's `Justfile` is matched against `justfile`, which only
   `nocasematch` makes true.)
2. **Fixed — the removal line said nothing about where to run it**
   (`install.sh:369`). Paths are relative to `$DEST`, and
   `./install.sh /path/to/project` is a documented invocation; pasted in a
   Keeler clone the line would stage that repository's own files. The prose
   above it now names the directory.
3. **Open — a Justfile from Keeler ≤ 0.3.0 is never detected**
   (`install.sh:347`). `keeler-spawn` first appears in v0.4.0
   (`git show v0.3.0:Justfile` has `crap-delta:` and `keeler-upgrade:` and
   no spawn recipe), so every adopter who installed before graph mode still
   has Keeler's `Justfile` at their root and is told nothing about it. The
   spec's Implementation Notes name `^keeler-spawn.*:` as the marker, so
   widening it — to `^keeler-upgrade:`, present in every release through
   v0.4.1 and gone after this spec — is a spec amendment, not a fix to make
   here. Proposed to the user.
4. **Open — `.cargo-mutants.toml` is matched by name alone**
   (`install.sh:333`). A project that wrote its own cargo-mutants config is
   told to `git rm` it — the false positive the justfile branch is
   content-checked to avoid. The Implementation Notes put it under "by
   path", so narrowing it (to a file whose content matches the one Keeler
   shipped) is a spec amendment. The cost is bounded: the report suggests,
   it never deletes, and every file is byte-identical afterwards.
