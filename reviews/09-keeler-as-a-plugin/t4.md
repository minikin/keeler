## Part 2 — generic review (`code-review`, high)

Findings, ranked. Every one that is not `docs/KEELER.md` names a file
another task owns, and each names the task.

1. **`KEELER.md` moved to `docs/KEELER.md` — needs the user's decision.**
   Spec 09 line 183 says it "stays where it is". It cannot: `keeler.md`
   and `KEELER.md` are one path on a case-insensitive filesystem, which is
   macOS's default and this machine's (`core.ignorecase=true`), and
   `git mv` refused the second file outright. Every scenario in T4, T5,
   T6, T7 and T11 names `keeler.md`, so the rules keep the name and the
   reasoning document moved. It is still in the repository and therefore
   still in the plugin, which is what the spec's sentence about it
   requires. **Proposed amendment: `docs/KEELER.md`.** External links to
   `/blob/main/KEELER.md` break either way; the ones inside this
   repository were updated.

2. **Spawned agents get no commands until T11.** `Justfile:574` writes a
   runner that starts `claude -p` with no `--plugin-dir`, and this commit
   deleted `.claude/commands/`. A task spawned now runs with the rules
   (this repository's `CLAUDE.md` imports them) but without `/keeler:tdd`
   and the rest registered as commands. T11 owns `_write-runner`, and it
   needs T8 and T9 first. Until it lands, spawn from a session started as
   `claude --plugin-dir .`, or expect the spawned agent to follow the
   pipeline from the rules rather than from the commands.

3. **The command files still name `.claude/` paths** — 13 references to
   `.claude/keeler.md` across eight of them, plus `feature.md`'s
   `.claude/commands/keeler/<stage>.md` and `spec.md`'s
   `specs/TEMPLATE.md`. T6 owns every one of these, under the scenarios
   _No command names a file Keeler no longer installs_ and _The spec
   command prefers the project's template_.

4. **The spawn prompt names the rules at their old path.** `Justfile:511`
   still says "then .claude/keeler.md". T11, scenario _A spawned agent is
   told where the rules are_.

5. **`keeler --list` names a wrapper that arrives in T8.** The rules say
   it because the scenario _The rules say where the rest is_ requires it;
   `bin/keeler` is T8's deliverable. A transient the graph already
   orders.

6. **The retained rules still spell recipes `just <recipe>`.** The
   Change classes table says `just lint`, `just dev`, `just mutants-diff`,
   and `graph-mode.md` says `just keeler-spawn` throughout — moved
   verbatim, as the spec's layout note asks, and pinned that way by
   `tests/installer.rs`'s `assert_graph_mode_is_documented`. The spec
   mandates the `keeler` spelling for the Justfile's printed lines (T9,
   done) and for the commands (T6), and is silent about the rules. Raised
   as an open question rather than changed: no task owns it, and changing
   it would edit a test whose purpose is another spec's.
